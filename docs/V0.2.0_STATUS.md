# CellBridge Core v0.2.0

Implementation source prepared as a downloadable archive in the development conversation. This branch currently contains the version status only; the complete source has not yet been pushed to GitHub.

Scope: persistent host, authenticated loopback management API, SQLite registry, thin MCP stdio bridge, local management UI, managed upstream server lifecycles, and tool visibility controls.

Build and integration tests remain unverified because npm dependencies could not be installed in the execution environment. Do not treat this branch as a tested release.
