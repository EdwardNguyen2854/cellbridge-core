# Roadmap

- **v0.1.0:** MCP-to-MCP gateway via stdio, static server registry, namespaced tool discovery, forwarding, conservative read-only filter, structured stderr logs, mock integration tests.
- **v0.2.0:** Management API, server lifecycle controls, reconnect/restart and refreshed tool discovery.
- **v0.3.0:** Local management UI, server and tool explorer, connection diagnostics.
- **v0.4.0:** Workbook/session-aware routing, standardized Excel tool adapters, granular permissions.
- **v0.5.0:** Harness profiles, configuration generation and optional remote transport.
- **v1.0.0:** Windows Excel E2E validation, safe updates/rollback, hardened security and production documentation.
